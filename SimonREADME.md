# Simon Game 🎮

A simple **Simon Game** built using **HTML, CSS, and JavaScript**.

The player has to remember and repeat the sequence of colors shown by the game. With each level, the sequence gets longer and the game becomes more challenging.

## Features

* 🎨 Color-based sequence gameplay
* 📈 Increasing difficulty with each level
* 🧠 Tests memory and concentration
* 💻 Built with vanilla JavaScript
* 🎮 Simple and interactive UI

## Tech Stack

* HTML
* CSS
* JavaScript

## How to Play

1. Press any key to start the game.
2. Watch the color sequence carefully.
3. Click the buttons in the same order.
4. Each correct round increases the level.
5. One wrong button ends the game.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/simon-game.git
```

Open the project folder and launch `index.html` in your browser.
