# Todo App 📝

A simple Todo List web application built using **HTML, CSS, and JavaScript**.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Simple and clean user interface
* Dynamic task management using JavaScript

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
Todo-App/
├── index.html
├── style.css
├── app.js
└── README.md
```

## How to Run

1. Download or clone the repository.
2. Open the `Todo-App` folder.
3. Open `index.html` in your browser.
4. Start adding and managing your tasks.

## Purpose

This project was created as a **JavaScript mini project** to practice DOM manipulation, event handling, and basic JavaScript logic.
